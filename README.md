# Fashion E-Commerce Mobile App – UI/UX Case Study

## Project Overview
This project is a mobile e-commerce UI/UX design created to provide a smooth and intuitive shopping experience.

## Problem Statement
Users need a simple, clean, and fast way to browse products, add items to cart, and complete purchases without confusion.

## Solution
Designed a minimal and user-friendly mobile shopping flow including:

• Login Screen
• Home Page with categories
• Product Detail Page
• Add to Cart
• Checkout Summary
• Payment Method Screen

## Design Goals
- Clean pink aesthetic theme
- Clear call-to-action buttons
- Easy navigation
- Simple checkout process

## Tools Used
Figma

## Key Features
- Modern UI design
- Structured checkout flow
- Visual hierarchy
- Consistent color palette
